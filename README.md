# 🏏 TATA IPL 2022 Data Analysis Project

## 📌 Overview
This project analyzes the TATA IPL 2022 season using SQL and Power BI to uncover insights related to team performance, player statistics, match outcomes, and season trends.

The project demonstrates skills in:
- Data Cleaning
- SQL Querying
- Exploratory Data Analysis (EDA)
- Data Visualization
- Dashboard Creation
- Sports Analytics

---

## 🎯 Objectives
- Analyze batting and bowling performances
- Identify consistent teams and players
- Compare win percentages across venues
- Discover match-winning patterns
- Visualize season statistics using Power BI

---

## 🛠️ Technologies Used
- SQL
- MySQL
- Power BI
- Excel / CSV
- Data Visualization

---

## 📂 Dataset
Dataset contains:
- Match-level data
- Ball-by-ball deliveries
- Player statistics
- Venue details
- Match outcomes

Source: Kaggle IPL Dataset

---

## 📊 Key Analysis Performed

### Team Analysis
- Most wins
- Highest run chases
- Best net run rate
- Toss impact analysis

### Batting Analysis
- Top run scorers
- Highest strike rates
- Most sixes and fours
- Orange Cap leaderboard

### Bowling Analysis
- Most wickets
- Best economy rates
- Purple Cap leaderboard

### Venue Analysis
- Highest scoring stadiums
- Toss advantage by venue
- Average first innings score
